# ReaperHub Design System

This design system establishes the visual foundation for the ReaperHub application. The aesthetic is "Dark, tactical, military-themed entertainment tracker." using terminology like Operative, Transmission, Intel, Targets, Killstreak, Mission, Dossier.

## 1. Typography
- **Display**: Sora (h1, h2 only)
- **Headings**: Outfit Bold (h3-h6)
- **Body**: Outfit Regular
- **Mono**: JetBrains Mono (stats/numbers)

### Scale
- 12px, 14px, 16px, 18px, 20px, 24px, 32px, 48px, 64px
- Line Heights: 1.2 (Headings), 1.6 (Body)

## 2. Color Palette
- **Base Background**: `#0a0b0f`
- **Elevated Background**: `#13141a`
- **Overlay Background**: `#1c1d24`
- **Hover Background**: `#252631`
- **Text Primary**: `#fafafa`
- **Text Secondary**: `#a1a1aa`
- **Text Muted**: `#71717a`
- **Text Disabled**: `#52525b`
- **Primary Accent**: `#8B5CF6` (Purple)
- **Secondary Accent**: `#e63946` (Red)
- **Success Accent**: `#10b981` (Green)
- **Warning Accent**: `#f59e0b` (Amber)

## 3. Spacing System
Base unit of 4px.
Scale: 4px, 8px, 12px, 16px, 20px, 24px, 32px, 40px, 48px, 64px, 80px, 96px

## 4. Radii & Borders
- **Border Radii**: 4px (sm), 8px (md), 12px (lg), 16px (xl), 24px (2xl)
- **Borders**: Subtle, Default, and Strong variants mapped to surface layers and muted text.

## 5. Shadows
Five levels of depth/elevation for elements plus accent-based glow effects.

## 6. Motion
Standard easing: `cubic-bezier(0.16, 1, 0.3, 1)`
Durations: 100ms (instant), 200ms (snappy), 300ms (default), 500ms (smooth).
